**核心结论**：FlowTask 在**功能层已经和 Asana 分家**——四状态（含原创的「已暂停」）、个人/共享双库、实体级三路合并、导出中心、筛选视图、账户隔离，这些 Asana 都没有。Asana 味集中在**品牌层（logo/主色/定位语）+ 五个交互签名**（导航三件套、视图页签、Tab+Q、状态更新三色心情、抽屉视觉组合）。去 Asana 不需要动功能架构，只需要换身份表达。

## 改版机会点（按优先级）

### 🥇 高

**机会点 1：品牌身份重塑——从「仿 Asana」到「本地优先任务台」**（r3-1 / r3-2 / r3-8）
成本最低的三刀：换 logo、换品牌色、删光「仿 Asana」定位语。产品真正的差异化资产（单文件零依赖、数据在自己盘上、局域网协作、断网可用）从未在视觉与叙事上被主张——一直在用别人的脸介绍自己。

**机会点 2：导航与功能命名去 Asana——只换壳不换功能**（r3-3 / r3-4 / r3-6 / r3-7 / r3-14）
「首页/我的任务/收件箱」三件套、概览/进度页签、状态更新三色心情是 Asana 用户的既视感触发器。功能都成立，改命名与表达形态即可。品类通用词（列表/看板/日历/任务/子任务）保留——不为差异化牺牲可用性。

### 🥈 中

**机会点 3：键盘优先的身份招牌——Ctrl+K 命令面板替换 Tab+Q**（r3-5 / r3-15 / r3-16）
与其删掉 Asana 招牌快捷键，不如换成自己的招牌动作：命令面板聚合搜索/新建/跳项目/切视图。这是本地工具用户最吃的一套（Linear/Raycast 心智），一次改造同时完成「去 Asana」和「加身份」。

**机会点 4：设计系统收口——令牌裁决 + emoji 图标清零 + 反馈语法**（r3-9 / r3-10 / r3-11）
两轮遗留的视觉债：DESIGN.md 与实现两张皮（h1 22px vs 规范 19px、圆角 35 处档位外、z-index 20 声明 vs 七档）、约 50 处 emoji 功能图标、抽屉编辑反馈不一致。这是「成品感」的最后一段路，配源码守卫单测防回潮。

### 🥉 低

**机会点 5：规模化收尾——列表懒渲染 + 撤销增强**（r3-12 / r3-13）
300 任务一次性全量渲染（perf-300 截图为证）；撤销 6 秒且丢通知。退化型问题，但暂无真实大数据反馈，排在身份重塑后。

## 去 Asana 专项方案（三级清单）

### 必改（最强信号，改动成本 < 1 天）

| 现状（Asana 味） | 建议（FlowTask 身份） |
|---|---|
| Logo：三点+连线（≈Asana 三圆点轨道标） | 换「本地优先」意象：单机/盒子/对勾/局域网节点；顶栏+登录页+桌面图标四处统一 |
| 主色 #E24D5C 珊瑚红（Asana 品牌色同族） | 深青（#0F766E 系）/靛蓝/墨绿任一；避开「珊瑚红+白底高密度」组合 |
| README 首行「仿 Asana」、DESIGN.md「风格定位：仿 Asana」、代码 13 处「对标 Asana」注释 | 定位语改「单文件、零依赖、数据不出电脑的团队任务管理」；注释改为陈述自身设计意图 |
| 侧栏三件套：首页 / 我的任务 / 收件箱 + 铃铛 | 首页→**今天**、收件箱→**动态**；「我的任务」保留（行业通用）。侧栏分组改「个人 / 项目 / 系统」 |
| 状态更新 + 三色心情（进展正常/存在风险/进度落后 = Asana Status Updates） | 改名「项目播报」或「本周进展」；三色 pill 改为进度% + 一句话，或纯圆点去胶囊 |

### 建议改（次级信号，随下轮迭代顺手做）

| 现状 | 建议 |
|---|---|
| Tab+Q 快速添加（Asana 招牌快捷键，且引导弹窗在教学） | Ctrl+K 命令面板；Tab+Q 退役；快捷键文档收进单一 KEYMAP 常量 |
| 视图页签「概览/…/进度」对位 Overview/…/Timeline | 概览→详情、进度→排期（或甘特）；列表/看板/日历不动 |
| 侧栏项目 = 彩色圆点 + 名称（Asana 式） | 圆点→首字母色块（Notion 式）即可大幅改变印象 |
| 空心圆勾选完成（Asana/Jira 混合，可留） | 若想再拉开距离：改方形复选框（Jira/Todoist 式）；二选一即可，别全改 |
| 「点击成员卡片选择」等「卡片」措辞残留 | 按自家术语表清掉 |

### 不要改（品类通用，改了反而伤可用性）

任务/子任务/负责人/关注人/优先级高中低字段集（Jira、Todoist、ClickUp 全有）；列表/看板/日历三视图与拖拽改状态；看板列=状态的默认工作流；右侧详情抽屉模式（现代 PM 工具通用范式）；彩虹标签 pill；「我的任务」这个词。
